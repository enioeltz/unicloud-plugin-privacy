Política de Privacidade

BlocoPro Plugin Unicloud - Versão 2.0

Responsável: Unitel Telecom

Última atualização: 09/11/2026

Esta Política de Privacidade descreve como a extensão BlocoPro Plugin Unicloud utiliza informações para disponibilizar a funcionalidade Click2Call na plataforma BlocoPro V2.

1. Finalidade da extensão

A extensão permite iniciar chamadas telefônicas diretamente da interface do BlocoPro V2, utilizando a infraestrutura de telefonia Unicloud da Unitel Telecom.

A solicitação de chamada é iniciada pelo usuário mediante o acionamento do botão Click2Call.

2. Informações utilizadas

Para executar sua funcionalidade, a extensão utiliza:

  • Usuário, token de autenticação e ramal de origem configurados pelo usuário.
  • Número telefônico do contato apresentado no BlocoPro.
  • Identificadores técnicos das instâncias associadas ao atendimento.
  • Informações de contexto do atendimento necessárias à integração.

3. Utilização das informações

As informações são utilizadas exclusivamente para identificar o contato, preparar a solicitação de chamada e encaminhá-la à API Unicloud.

A extensão acessa informações da interface e das respostas de requisições do BlocoPro necessárias à integração. Não possui como finalidade coletar o conteúdo das mensagens dos atendimentos.

4. Armazenamento das credenciais

As configurações de usuário, token e ramal são armazenadas localmente no navegador por meio de chrome.storage.local.

O acesso direto ao armazenamento é restrito aos contextos confiáveis da extensão, por meio de TRUSTED_CONTEXTS. Essa restrição não constitui criptografia própria dos dados armazenados.

5. Comunicação com serviços externos

A extensão utiliza os seguintes serviços:

  • BlocoPro V2: identificação das informações necessárias ao atendimento e integração do botão.
  • API Unicloud: envio autenticado das solicitações de Click2Call.

As solicitações à API Unicloud são transmitidas por HTTPS. A infraestrutura de telefonia poderá manter registros operacionais das chamadas conforme suas práticas e obrigações aplicáveis.

6. Compartilhamento e finalidade dos dados

As informações necessárias à chamada são transmitidas à infraestrutura Unicloud para executar o serviço solicitado.

A extensão não utiliza dados pessoais para publicidade, venda de informações ou avaliação de crédito.

7. Controle pelo usuário

O usuário pode atualizar suas configurações na página de opções da extensão.

A remoção da extensão normalmente elimina os dados locais associados a ela no perfil do navegador.

8. Segurança

A extensão utiliza permissões específicas para os domínios necessários à integração e não executa código JavaScript remoto.

A proteção das credenciais também depende da segurança do dispositivo e do perfil do navegador utilizado.
